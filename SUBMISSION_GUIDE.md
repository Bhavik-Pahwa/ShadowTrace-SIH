# SIH 2026 Submission Guide

Use this checklist before sharing the GitHub repository link with reviewers.

## Required Repository Content

- [x] Actual source code is present.
- [x] `README.md` explains the project clearly.
- [x] PS ID and PS title are included.
- [x] Problem statement and proposed solution are explained.
- [x] Key features are listed.
- [x] Technology stack is listed.
- [x] Setup and run instructions are included.
- [ ] Team member names and roles are finalized in `README.md`.
- [ ] Important screenshots or prototype photos are added when available.
- [x] Presentation artifact or presentation link is documented in `submission/`.
- [x] Demo video link placeholder is documented in `submission/DEMO.md`.
- [ ] Repository access is verified from a logged-out/private browser session.

## Before Final Submission

1. Replace the placeholder team-member rows in `README.md` with real names and
   roles.
2. Add important dashboard screenshots or prototype photos if the team wants
   reviewers to see output without running the app.
3. Add a public demo video link to `submission/DEMO.md` if a video is available.
4. Open the repository link in a private/incognito browser window and confirm
   that the code, presentation, documentation, release assets, and any submitted
   links are accessible without requesting permission.

## Do Not Upload

- Passwords
- API keys
- Access tokens
- `.env` files containing secrets
- Private credentials
- Other confidential information
